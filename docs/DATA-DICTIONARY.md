# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 primary, duplicate, control。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `sample`、`concentration`、`lod`、`loq`、`limit` 排列。最终值单位见阶段结果。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

浓度整数为微克每升。双方低于检出限标为共同未检出；一侧低于检出限进人工复核。双方均达到 5 倍定量限时用相对偏差，其余用绝对差。用整数交叉积比较边界，显示值按基点向下取整。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。
